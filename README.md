# 🎬 NETFILM MOVIE WEBSITE

A modern and responsive movie website built with **React.js**. Explore movies through an engaging user interface with movie posters, details, and a smooth browsing experience.

🔴 **Live Demo:** [View Movie Website](https://movie-website-kdk6toymr-aakib-jr1.vercel.app/)

---

## ✨ Features

- 🎥 Modern and user-friendly movie website interface
- 🖼️ Movie posters and visual content
- 📱 Responsive design for desktop, tablet, and mobile devices
- 🔍 Movie browsing experience
- 🎞️ Interactive sliders and carousels
- ⚡ Fast performance powered by Vite
- 🧭 Smooth navigation between pages
- 🎨 Styled using Bootstrap and custom CSS

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| React.js | Frontend development |
| Vite | Development server and build tool |
| JavaScript | Application functionality |
| Bootstrap 5 | Responsive styling |
| Swiper.js | Interactive sliders and carousels |
| HTML5 | Website structure |
| CSS3 | Custom styling |
| Vercel | Deployment and hosting |
| Git & GitHub | Version control |
